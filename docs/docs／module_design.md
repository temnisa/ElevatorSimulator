# モジュール設計書

## 1. 目的

エレベーター制御シミュレータの各機能を分割し、保守性および拡張性を向上させる。

---

## 2. モジュール構成

```text
main
 ├─ Elevator
 ├─ Display
 └─ Input
```

---

## 3. モジュール一覧

### 3.1 Mainモジュール

#### 役割

システム全体の制御を行う。

#### 主な処理

* 初期化
* メインループ実行
* 各モジュール呼び出し
* 終了処理

#### ファイル

```text
main.c
```

---

### 3.2 Elevatorモジュール

#### 役割

エレベーター本体の状態を管理する。

#### 管理データ

* 現在階
* 目標階
* 動作状態

#### 主な処理

* 上昇処理
* 下降処理
* 到着判定
* 状態更新

#### ファイル

```text
elevator.c
elevator.h
```

---

### 3.3 Inputモジュール

#### 役割

利用者入力を受け付ける。

#### 主な処理

* 行先入力
* 入力値チェック
* エラー判定

#### ファイル

```text
input.c
input.h
```

---

### 3.4 Displayモジュール

#### 役割

画面表示を行う。

#### 主な処理

* 現在階表示
* 状態表示
* エラー表示
* 到着メッセージ表示

#### ファイル

```text
display.c
display.h
```

---

## 4. データの流れ

```text
ユーザー
 ↓
Input
 ↓
Main
 ↓
Elevator
 ↓
Display
 ↓
画面
```

---

## 5. 状態管理

エレベーターは以下の状態を持つ。

* STOP
* MOVING_UP
* MOVING_DOWN
* DOOR_OPEN

状態遷移は state_diagram.md に従う。
